# visualization

房贷月供与提前还款计算、工作性价比、倒计时等本地可视化工具。服务端使用 Java 8 / Spring Boot，房贷页面所需的脚本、样式与图表资源均随应用发布。

## 构建发布包

构建机器需要 JDK 8 和 Maven。首次构建需要联网下载公开依赖；项目专用设置使用 Maven Central，不修改机器的全局 Maven 配置：

```bash
mvn -s script/maven-settings.xml package
```

依赖和构建插件缓存齐备后，可以断网重新测试、打包：

```bash
mvn -o -s script/maven-settings.xml package
```

发布包是 `target/visualization-0.0.1-SNAPSHOT.tar.gz`，包含应用、全部运行时依赖、静态页面、配置和数据文件。将这个完整压缩包复制到离线机器即可，不需要在离线机器安装 Maven、Node.js 或下载前端依赖。离线机器需预先安装 Java 8。

## 离线启动

```bash
tar -xzf visualization-0.0.1-SNAPSHOT.tar.gz
cd visualization-0.0.1-SNAPSHOT
bash start.sh
```

默认访问地址：

- 房贷计算器：<http://localhost:8080/calculator/index.html>
- 工作性价比：<http://localhost:8080/workCost/index.html>
- 倒计时：<http://localhost:8080/countdown/index.html>

房贷计算和图表、工作性价比、倒计时可以在没有互联网的环境运行。浏览器仍需能连接本机或局域网内的 Java 服务；直接双击 HTML 文件无法调用后端接口。LPR 使用应用内置的历史数据，断网时不会自动获取新的报价。

`route` 是独立的地图实验页，仍依赖在线地图服务，且仓库未提供其引用的 `car1.csv`。它不属于可离线运行的计算器功能，当前不能作为完整离线地图使用。

停止或重启：

```bash
bash stop.sh
bash restart.sh
```

启动脚本会进入发布目录，正确加载外部配置，并将启动输出写到 `logs/startup.log`。进程记录在 `logs/visualization.pid`；停止脚本只操作该发布目录记录的应用进程。业务日志在 `logs/visualization.log`，端口在 `config/application.yml` 中配置。

工作性价比的数据保存在 `config/percent.json` 和 `config/workCostData.json`，发布目录需要有写权限；升级前请备份这两个文件。房贷计算结果不写入这两个文件。

## 房贷测算与账单核对

页面保留等额本息、等额本金、多次提前还款、缩短期限/降低月供、趋势图和可复制的还款明细，新增 CSV 导出。提前还款默认按合同重定价周期自动解析当时利率，也可切换为手动。

- **每年 1 月 1 日重定价**：不会因 LPR 每月发布而立即调整。页面纳入一般首套房贷的 2023/2024 历史批量加点调整，政策事件与年度 LPR 重定价独立；只调整加点，不同时刷新 LPR。接口仍可显式关闭政策估算，用于当地下限、资格或银行执行规则不同的合同。
- **建行账单对照**：页面固定采用分段计息（30/360），已移除“更多合同条件”。90 万元、30 年、5.63%、2021-08-27 首期的样例已核对 62 期月供和 2 笔提前还款，64 笔交易的月供、本金、利息和本金余额最大误差均为 0.00 元；回归测试上限统一为 0.02 元。2023 年批量调息保留已出账月供和计划本金，新利率立即分段生效；利息不足一分的尾数连续结转，等额本息月供向上取分。实际提前还本重建计划后，月供及后续重定价计入首期额外应计息现值。这些精度与计划规则由本合同完整实账验证，不能推及所有银行合同，首尾非整月仍未覆盖。详见 [建行全期对账记录](docs/mortgage-ccb-reconciliation.md)。
- **合同周期**：页面支持 3/6/12 个月，使用所选重定价日起算。该周期用于整条测算时间线；若贷款中途变更周期，不能把新周期直接当成整个历史合同的规则。
- **离线利率数据**：`LoanUtil.FIVE_YEAR_LPR` 仅记录 5 年以上 LPR 的变动节点，`LPR_UPDATED_AT` 记录最后核验日期。更新须核对官方历史公告、修改数据与核验日期、重新测试打包。未来未知报价沿用最后已知值。当前模型面向商业住房贷款，不覆盖公积金及组合贷款。

实现将合同利率事件与逐期金额计算分开，并以逐期分位记账和末期结清处理尾差。已覆盖零利率、同月多笔提前还款、年末调息、月末锚点、历史政策不抬高较低加点、全额结清等回归。银行规则与本次账单验证依据见 [房贷计息与 LPR 核查](docs/mortgage-interest-research.md)。

页面以手机为主要使用场景：单列输入、48px 输入控件、44px 操作区域，结果的本金/利息双列及节省金额单独展示。手机默认使用可横向滑动的原生明细表格，保留交互表格切换与 CSV 导出。图表实例复用且不播放进场动画，重复计算不再整体淡入淡出。后端仍保留显式整月口径和政策调息参数，供已核对合同的接口调用使用，页面不开放这些高级参数。
